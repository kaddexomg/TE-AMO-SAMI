Demo: imagen completa con object-fit: contain

Coloca imágenes en la carpeta images/. Este demo no modifica las imágenes originales; solo aplica estilos para mostrarlas completas.

Imagen inline sin recortes

Background como contenedor

Notas: si el contenedor tiene aspect-ratio o un alto explícito, object-fit: contain escala la imagen para que se vea completa sin recortar. Si prefieres que la imagen rellene el contenedor y pueda recortarse, usa object-fit: cover o background-size: cover.
